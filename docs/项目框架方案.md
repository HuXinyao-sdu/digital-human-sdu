## 1. 项目确认

- **项目名称**：让历史动起来
- **院级立项**：山东大学人工智能学院
- **聚焦范围**：山东大学趵突泉校区百年校史（1901至今）
- **一句话定位**：让百年校史"活"起来——AI数字人实时讲解、老照片彩色修复、RAG智能问答的交互式校史体验平台。
- **已有基础**：
  - 黑白老照片修复彩色化照片若干
  - 动态化图片几张
  - 老舍、侯宝璋讲话视频各一个（7-10分钟）
  - RAG检索知识库问答系统与题库网站

### 项目要解决的3个问题
1. **校史传播形式单一**：现有校史以文字、静态照片为主，年轻学生觉得"离自己远"
2. **历史资料分散**：事件、人物、建筑、照片散落在不同文献中，缺乏结构化整合
3. **缺乏互动性**：传统校史展示是"看"，不是"聊"，学生无法随时提问

## 2. 核心闭环

```
校史资料收集（事件/人物/建筑/老照片）
   ↓ 整理为结构化Markdown + JSON索引
数字人讲解脚本撰写（按时间轴分主题，口语化）
   ↓
离线生产：TTS生成音频 → EchoMimic生成讲解视频
   ↓
用户访问网站
   ├── 主动讲解：点击时间轴节点 → 播放对应AI讲解视频 + 展示老照片
   ├── 互动问答：输入问题 → RAG检索校史知识库 → 数字人语音回答
   └── 浏览探索：时间轴漫游 + 老照片图库 + 题库测试
   ↓
讲解内容与RAG知识库双向校准，保证史实准确
```

## 4. 关键接口（黑盒定义）

### 4.1 问答接口

```
POST /api/chat

请求：
{
  "question": "老舍在山大做了什么",
  "session_id": "可选，多轮对话用"
}

响应：
{
  "answer": "老舍1930-1934年任教于国立山东大学...",
  "sources": ["《山东大学百年史》P123"],   // 引用来源
  "session_id": "xxx"
}
```

- 后端收到请求后，转发到已有RAG系统
- RAG未配置时，返回关键词匹配的模拟回答

### 4.2 内容接口

```
GET /api/content/scripts
→ { total: 6, items: [{id, title, era, duration}] }

GET /api/content/gallery
→ { total: 30, items: [{id, title, era, location, image_url}] }
```

### 4.3 数据文件结构

所有素材在 `data/` 目录，后端直接读取：

```
data/history/
  events/*.md          # 每个事件一个Markdown
  figures/*.md          # 每个人物一个Markdown
  buildings/*.md        # 每栋建筑一个Markdown
  index.json            # 总索引

data/scripts/
  index.json            # 讲解脚本索引
  01-xxx.md             # 脚本正文

data/photos/
  manifest.json         # 照片清单
  1900s/xxx.jpg         # 按年代分文件夹

data/generated-videos/
  manifest.json         # 视频清单
  01-xxx.mp4            # AI生成的讲解视频
```

## 5. 数据模型（核心实体）

- **历史事件 Event**：年份、标题、背景、经过、意义、相关人物
- **历史人物 Figure**：姓名、生卒、在校时间、职务、经历、代表作
- **校园建筑 Building**：名称、建造时间、风格、历史变迁、现状
- **老照片 Photo**：标题、年代、地点、描述、原图路径、彩色化路径
- **讲解脚本 Script**：编号、标题、对应时间轴节点、时长、视频文件路径
- **问答对话 ChatSession**：会话ID、用户问题、系统回答、引用来源
