## 5. Git 协作流程

- **仓库**：https://github.com/HuXinyao-sdu/digital-human-sdu
- **分支**：`main`
- **每日流程**：
  1. 开始前：`git pull`
  2. 改完：`git add .` → `git commit -m "描述"`
  3. 推送前：`git pull` → `git push`
- **提交规范**：`feat:` / `fix:` / `data:` / `docs:` + 中文描述
- **不提交**：`node_modules/`、`venv/`、`__pycache__/`、`.env`、模型权重、大视频用Git LFS
